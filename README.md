# Dulfy May Cry — Unity Hack and Slash

Projeto pessoal desenvolvido em Unity e C#, com foco em programação de gameplay e sistemas de combate.

## 🎮 Sistemas implementados

- ⚔️ Sistema de combate e combos
- 🛡️ Sistema de vida do jogador e inimigos
- 🎯 Sistema de esquiva
- 👾 Inteligência artificial de inimigos
- 🏹 Inimigos arqueiros
- 🎥 Câmera em terceira pessoa
- 🔒 Sistema de Lock-On
- ⚡ Habilidades especiais
- 🎬 Animações e integração com Animator

## 🛠️ Tecnologias

- C#
- Unity
- Git/GitHub
- Visual Studio
- Animator
- Character Controller
- ScriptableObjects

## 🎯 Objetivo

Projeto criado para praticar e desenvolver conhecimentos em C# e desenvolvimento de jogos, aplicando conceitos de orientação a objetos, sistemas de gameplay, inteligência artificial e gerenciamento de estados.
