DulfyMayCry — Unity Hack and Slash

Projeto pessoal desenvolvido em Unity e C#, com foco em programação de gameplay e sistemas de combate.

Sistemas implementados

⚔️ Sistema de combate e combos
🛡️ Vida do jogador e inimigos
🎯 Sistema de esquiva
👾 IA de inimigos
🏹 Inimigos arqueiros
🎥 Câmera em terceira pessoa
🔒 Sistema de Lock-On
⚡ Habilidades especiais
🎮 Animações e integração com Animator

Tecnologias

C#
Unity
Git/GitHub
Visual Studio

Objetivo

Projeto criado para praticar programação em C# e desenvolvimento de jogos, aplicando conceitos de orientação a objetos, sistemas de gameplay, IA e gerenciamento de estados.
